# Shared Default Values Used Across Serverrun and Batchrun

This document summarizes the shared defaults used by Serverrun and the batch runners.
The values below reflect the core model defaults plus the scenario-specific overrides used by the batch runners.

## Baseline Scenario

| Parameter | Default Value | Notes |
| --- | --- | --- |
| Scenario mode | baseline | Flood and disease systems disabled |
| Visible charts | Population stability, Attendance, Infrastructure, Finance, Routine by hour | Default baseline chart set |
| Affected population series | Dead only | Minimal baseline affected chart |

## Flood Only Scenario

| Parameter | Default Value | Notes |
| --- | --- | --- |
| Scenario mode | flood_only | Flood dynamics enabled, disease systems off |
| Flood enabled | Yes | Core flood scenario |
| Mold enabled | No | Disabled |
| Infectious enabled | No | Disabled |
| Vectorborne enabled | No | Disabled |
| Affected population series | Evacuated, Stranded, Sheltered, Healthcare, Injured, Dead | Batch-style end-state affected metrics |
| Key business stressors | Flood closures, evacuation loss, repair costs | Main drivers of business wealth change |

## Flood Infectious Scenario

| Parameter | Default Value | Notes |
| --- | --- | --- |
| Scenario mode | flood_infectious | Flood + infectious disease enabled |
| Flood enabled | Yes | Core flood scenario |
| Infectious enabled | Yes | Starts by default on the second post-flood day |
| Mold enabled | No | Disabled |
| Vectorborne enabled | No | Disabled |
| Infectious disease start hour | Flood end + 48 hours | Calculated from the configured pre-flood and flood durations; Serverrun permits user adjustment |
| Affected population series | Evacuated, Stranded, Sheltered, Healthcare, Injured, Dead, Ever Infected | Flood and infectious outcomes only |

## Compound Scenario

| Parameter | Default Value | Notes |
| --- | --- | --- |
| Scenario mode | compound | Flood + mold + vectorborne + infectious enabled |
| Flood enabled | Yes | Core flood scenario |
| Mold enabled | Yes | Enabled |
| Vectorborne enabled | Yes | Enabled |
| Infectious enabled | Yes | Enabled |
| Infectious disease start hour | Flood end + 48 hours | Default is the second post-flood day, calculated from the configured pre-flood and flood durations; Serverrun still permits any absolute hour |
| Initially infected population | 1% | Percentage infected when the disease begins |
| Affected population series | Evacuated, Stranded, Sheltered, Healthcare, Injured, Dead, Mold, Vectorborne, Ever Infected | Batch-style end-state affected metrics |
| Key business stressors | Flood closures, mold penalties, vector costs, infection-driven work loss, repairs | Highest combined wealth pressure |
